# Features

> analyzer and eduroam support will come soon.

**Connect to Wi-Fi easily -** It can select the right Wi-Fi you need, automatically perform account verification without visiting 10.9.0.4 manually. It also support eduroam.

**Analyze connecting failure -** When errors happen from network connection, it can analyze what gets wrong and provide easy to understand explanations instead of error codes.

**Fix errors in background -** It can fix errors that cause network connecting failure in your computer automatically. You can also select what to check by yourself.

# Installation

> The installation pack will come soon in the release.

Download the installation pack in the release, then move to the location you want to install it, and click it.

You can choose the installation location at your own discretion.

It will expand into a folder as following:

```
netool
    -- run.exe
    -- bin
        -- analyze.exe
        -- gui.exe
        -- kernel.exe
```

**Click `run.exe` to run this software.**

Delete `netool` folder to uninstall this software.
